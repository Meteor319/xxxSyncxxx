# 風格規格（固定沿用）

## 1. 紙張與列印
- A4 直式 210×297mm；`@page { size: A4 portrait; margin: 0 }`，每頁 `.page` 固定寬高、內距 10mm、`overflow: hidden`。
- 每頁 `page-break-after: always; break-after: page`，最後一頁設為 auto。
- `-webkit-print-color-adjust: exact; print-color-adjust: exact`，確保灰底與點陣印得出來。
- 螢幕預覽時頁面放在淺灰底上並加陰影；`@media print` 時去掉陰影與外距。
- 每頁內容必須完整放進該頁，不可溢出到下一頁。

## 2. 色彩（純灰階，不用任何彩色）
- 墨色 ink `#1c1c1c`：主線條、主文字
- 中灰 mid `#555`：注音、提示文字
- 淺灰 soft `#9c9c9c`：虛線、次要框
- 線灰 line `#c4c4c4`：分隔虛線
- 底灰 tint `#efefef`／`#dcdcdc`：區塊或地圖填色
- 任務標籤：深灰 `#333` 底、白字
- 不使用 emoji（列印時會變彩色或缺字），改用自繪線條圖示。

## 3. 字體與字級
- 中文：Noto Sans TC（400/500/700/900），備援 PingFang TC、Microsoft JhengHei。
- 英文：Nunito 800/900（圓體粗字），英文單字一律粗體大字。
- 字級以 mm 為單位：任務標題 5.6mm/900；單字卡中文 5–5.8mm/900；內文 4.2–4.4mm/700；注音 2.6–2.8mm/500 中灰；提示 3–3.2mm 中灰。
- 頁首主標 8mm/900，字距約 0.8mm。

## 4. 注音標註規則
- 每個重點中文詞都用直排結構：上面是粗體中文，正下方置中放注音（`.w > b` 加 `.w > i`），注音不換行、字距 0.15mm。
- 輕聲用「˙」標示，例如 ㄇㄠˋ ㄗ˙。
- 讀音有爭議的字（例如「焢」）不標注音，避免教錯。

## 5. 版面結構
- **頁首資訊欄**（每天第一頁）：圓角 5mm、框線 0.7mm 的大框，左右兩欄。
  - 左欄（約 58mm）放主題圖示、主標＋注音、英文副標，以及「第一天 Day 1」膠囊標籤，用虛線和右欄隔開。
  - 右欄放姓名（虛線底線）、日期、今日方向（英文大字＋箭頭圖示＋中文注音），以及一個趣味填寫欄。
- **續頁窄條**（每天第二頁）：一行小字寫主題、天數、日期和姓名欄，下方一條 0.6mm 實線。
- **任務區塊**：圓角 4mm、框線 0.5mm，內距 3×4mm，區塊間距 3.5mm。最後一個區塊用 flex:1 撐滿剩下的高度。
- **任務標題列**：「任務 N」深灰膠囊標籤，接中文標題 900 字重和英文副標，可加一段灰色副標；操作提示（例如「放進包包，就打勾 ✓」）靠右放。

## 6. 互動元件
- **勾選方塊**：9–10mm 正方形，框線 0.6mm、圓角 1.8mm，放在每列最右側。
- **單字卡**：0.4mm 框、圓角 3mm，內容依序是線條圖示、中文＋注音、英文粗體。
- **裝備卡**：四欄網格，每格由上而下是大圖示（18mm）、中文、注音、英文和勾選方塊。
- **圈選選項**：虛線膠囊（0.35mm 淺灰虛線、全圓角），裡面放中文＋注音＋英文，讓小朋友直接圈。
- **題號**：圓圈內放 Nunito 粗體數字（7mm）。
- **成就打勾列**：依序是圖示、中文＋注音、靠右的勾選方塊，列與列之間用淺灰虛線分隔。
- **手寫線**：0.45–0.5mm 虛線底線，高度 8–14mm，適合幼兒握筆書寫。
- **表情圈選**：開心、普通、一點點三種線條臉，每張臉下方附文字。
- **塗色元素**：空心大愛心（9mm）、空心大星星（13mm），旁邊附提示「塗滿它！」。
- **印章圈**：16mm 虛線圓，圓內寫「打勾或蓋章」。

## 7. 畫圖區
- 大畫布：圓角 6mm、框線 0.7mm，底紋是點狀網格（5mm 間距，點直徑約 0.6mm，色碼 `#a9a9a9`）。
- 左上角放白底標籤（「小小畫家專區」加上畫圖提示），底部放白底填寫列（例如「我的火車頭叫做：____」）。
- 右下角放一個極淡的示範圖示（`#c4c4c4` 線條）當提示。
- 畫布至少佔該頁版面的 1/3。

## 8. 線條圖示
- 全部自繪內嵌 SVG `<symbol>`，viewBox 0 0 64 64，集中放在頁面頂端 `<defs>`，需要的地方用 `<use>` 引用。
- 只用描邊不用填色：stroke `#1c1c1c`、寬 2.2、圓頭圓角。需要分出明暗時，只用白色或 `#8a8a8a` 小面積填色。
- 風格簡約可愛，例如小車車、火車頭、鐵軌、扇形車庫、風車、海豚、海浪、輪船、碗、餅乾、禮物盒、獎章、星星、愛心、指北針、上下箭頭。
- 不畫任何既有卡通角色或品牌圖案。

## 9. 路線軸
- 直向時間軸：左側一條粗灰虛線（1.2mm），把各站串成一條線。
- 縣市站用 9mm 黑底白字的編號圓點（Nunito 粗體），途經點用 6.4mm 空心圓。
- 每站一列，依序是起點／終點小標籤、地名（6–6.6mm 粗體）＋注音、灰色英文名，最右邊放印章圈。
- 途經點放圖示＋中文注音（例如穿過山洞、休息站、跨過溪）。
- 回程頁的路線由下往上排，起點在下、終點在上，讓小朋友直覺感受「向北」。

## 10. 台灣地圖（有地圖需求時）
- 用真實縣市界線繪製，不用手繪示意圖。資料來源是 npm 套件 `taiwan-atlas` 的 counties-10t.json，搭配 topojson-client 和 d3-geo（geoMercator + fitWidth）產生內嵌 SVG。
- 排除離島（連江、金門、澎湖），並濾掉面積太小的小島，讓輪廓乾淨。
- **全島分區圖**：
  - 北部（北北基桃竹竹宜）淺灰實底；中部（苗中彰投雲）白底；南部（嘉嘉南高屏）斜線紋；東部（花東）點點紋。
  - 縣界用細灰線，區界用 2.4px 黑粗線，路線經過的縣市邊框也加粗。
  - 區名放大（約 21px/900）並附注音；文字加白色描邊，壓在紋理上也看得清楚。
- **放大路線圖**：只顯示行經的縣市（白底粗框），其他縣市用淺灰。海面用波浪紋，海峽和大洋要標名。
- **路線畫法**：
  - 主路線用黑色粗線（約 4px），外圍加白色描邊並帶箭頭；去程用虛線。
  - 對照路線（例如另一天走的路）用灰色細虛線。
  - 停靠點用黑底白字編號圓，編號和左側路線軸一致，讓小朋友左右對照。
- 必附 N/S 指北針與圖例。地圖下方加一句孩子看得懂的提示，例如「找一找：我們從北部開到中部！」。
- 版面配置：路線軸放左欄，地圖放右欄（約 75mm 寬），格線用 `minmax(0,1fr) 75mm`，避免撐破版面。

## 11. 證書
- 雙層框：外框 1mm 實線、內框 0.45mm 虛線，四個角放星星圖示。
- 上方是兩枚獎章圖示夾住標題，標題上方加字距很寬的「Certificate」灰色小字。
- 內文行距 2，留姓名底線、日期和任務名稱。底部左邊放日期，右邊放「專屬領隊（爸爸簽名）」欄位。

## 12. 文字語氣
- 用孩子的口吻和短句：「找到了，就打勾 ✓」「圈出我的表情」「塗滿它！」。
- 任務名稱生動具體，例如「火車頭的大城堡」「小小烘焙師出任務」。
- 每個任務至少要有一種動手的互動（勾、圈、畫、塗、寫）。

# 製作與驗收流程
1. 先寫完 HTML，再用 Playwright（Chromium）開啟頁面檢查：
   - 每個 `.page` 內的元素都沒有超出 10mm 安全邊距；
   - 各區塊的 scrollHeight 沒有大於 clientHeight；
   - 輸出 A4 PDF（無邊界、印背景）時頁數剛好等於規定頁數。
2. 每頁截圖逐一目視檢查：文字不重疊、注音對齊、地圖標籤沒被遮住。
3. 有問題就修正再重測，直到全部通過才交付。
4. 交付時附上列印說明：用 Chrome 列印，紙張選 A4，邊界選「無」，並勾選「背景圖形」。
