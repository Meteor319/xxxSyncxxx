### 產出物三：`AOP_Interactive_Dashboard.html`（給老闆與會議投幕用的單檔互動式儀表板）

請撰寫一個生成腳本 `05_build_dashboard.py`，讀取對平後的 `verified_aop_data.json` 與對齊結果，自動渲染並輸出一個**100% 獨立運作的單一 HTML 檔案**。請嚴格遵守以下技術與介面規範：

#### 1. 技術架構與防呆限制 (Technical Constraints)
- **Zero-Server / 拒絕 CORS 報錯（CRITICAL）**：嚴禁在 HTML 中使用 `fetch()` 或 `XMLHttpRequest` 讀取外部 JSON。請透過 Python 腳本直接將完整結構化資料序列化後，內嵌至 HTML 的 `<script>const AOP_DATA = ...;</script>` 中，確保老闆在無網路或直接雙擊本地檔案（`file://` 協議）時能 100% 正常運作。
- **UI 與圖表庫（透過 CDN 引入）**：
  - 使用 **Tailwind CSS (CDN)** 打造現代、商務極簡的高階主管儀表板風格（深藍/石板灰為主色調，搭配清晰的狀態色）。
  - 使用 **Chart.js (CDN)** 繪製互動式圖表。
  - 使用原生 **Vanilla JavaScript** 或 **Alpine.js (CDN)** 實作即時過濾、搜尋與卡片展開互動。
- **列印與匯出友善**：加入簡單的 `@media print` 樣式，確保若老闆想將頁面另存為 PDF 時排版不會破版。

#### 2. 儀表板四大核心區塊設計 (Dashboard Layout)
- **區塊 A：頂部驗收狀態與 KPI 總覽列 (Top KPI Banner)**
  - 4 張核心指標卡：
    1. `AOP 總預估 HC`（顯示精確數字，並標註 `✅ 已與 [Summary!Cell] 100% 對平，誤差 0.00`）。
    2. `涵蓋 Gen / Project 總數`（顯示專案數與主要 BU 分佈）。
    3. `證據鏈完整度`（顯示 🟢 高度確信與 🟡 中度推論的 HC 佔比）。
    4. `🚨 需關注異常項`（統計 🔴 無文檔佐證 + ⚠️ 跨檔數字衝突的項目總數，使用醒目紅底提示）。

- **區塊 B：視覺化資源分佈圖表 (Visual Analytics - 2 Columns)**
  - **左圖（資源配置）**：各 Gen / Project 的 HC 佔比橫向長條圖或甜甜圈圖（點擊圖表項目可連動下方列表進行過濾）。
  - **右圖（季度趨勢或信心度結構）**：若原表有 Q1~Q4 / 月份資料，繪製整體 HC Ramp-up 堆疊趨勢圖；若無時間維度，則繪製「各專案之 🟢/🟡/🔴 信心度 HC 堆疊長條圖」，讓老闆一眼看出哪個專案的「黑盒調整」最多。

- **區塊 C：即時互動過濾器 (Sticky Filter & Search Bar)**
  - **燈號快速篩選按鈕（Pills）**：
    - `[全部專案 (All)]`
    - `[🟢 高度確信 (Verified)]`
    - `[🟡 脈絡推論 (Inferred)]`
    - `[🔴 待向 BU 確認 (Unexplained Magic Numbers)]`
    - `[⚠️ 跨檔資料衝突 (Transcript vs. Excel Conflict)]`
  - **BU / 世代下拉選單** 與 **關鍵字即時搜尋框**（可搜尋專案名、公式變數或逐字稿內容）。
  - **「全部展開 / 全部收合」切換按鈕**：方便會議中快速瀏覽或深潛。

- **區塊 D：專案深度拆解手風琴卡片 (Accordion Deep-Dive Cards)**
  - 每個 Gen/Project 呈現為一張結構化卡片：
  - **【卡片標題列（預設顯示）】**：
    - 專案名稱與所屬分類標籤
    - 預估 HC 數值（大字體）與佔總比 (%)
    - 一句話核心計算邏輯摘要
    - 狀態徽章（🟢 / 🟡 / 🔴 信心度燈號 + 若有衝突則顯示 `⚠️ 數字衝突` 標籤）
  - **【卡片展開抽屜（點擊後滑出 3 欄式明細）】**：
    - **左欄：`🧮 公式逆向工程與座標溯源`**
      - 顯示「語意展開後的白話公式」（以高對比色標出跨表參照的參數名稱與數值）。
      - 顯示原始 Excel 公式字串（`monospace` 字體）與精確來源座標 badge（如 `[SheetA!D15]`）。
      - 若有硬編碼常數（Magic Numbers），以醒目黃/紅框標示。
    - **中欄：`💬 逐字稿與 PPT 證據鏈`**
      - 列出配對到的會議逐字稿原文摘錄（附上精確 `[逐字稿: Line X]`）與 PPT 內容/備忘稿（附上 `[PPT: Slide Y]`）。
      - 若有跨檔數字衝突，在此欄以對比表格呈現：`Excel 最終值` vs `逐字稿/PPT 提及值`。
    - **右欄：`🛡️ 老闆與 BU 溝通攻防說帖 (Talking Points)`**
      - **增長/調整合理性說明**：供老闆對外解釋的重點摘要。
      - **會前必問 / 砍預算抓手**：針對 🔴 無佐證常數或高 Buffer 項目，提供具體的質詢問題（例如：「公式中直接乘上 1.25 但會議未提及，建議向 BU 確認是否重複計算複雜度係數」）。
